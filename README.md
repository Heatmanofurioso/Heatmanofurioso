# 

### 🏗️ What I'm focused on

- **Platform architecture** – Java/Spring Boot microservice platforms (KYC/AML, FinCrime) running on Kubernetes, with multi-tenancy as a hard constraint and data residency across EU, APAC and fully isolated sovereign deployments.
- **Multi-tenancy & multi-region** – tenant data segregation at row, schema and database level, global routing with Envoy / Gateway API, region-aware JWT claims, and fleet GitOps with Argo CD ApplicationSets.
- **Observability** – designing open-source, Grafana-native monitoring stacks (metrics, logs, traces, runtime security and SIEM) with multi-tenant isolation and OpenTelemetry instrumentation across Java, Python and Node.js.
- **Agentic engineering** – evolving teams from prompt engineering → context engineering → task-specific agents and skills. Currently building a vendor-agnostic, multi-model agent orchestration stack.
- **Mentoring & training** – helping engineers grow into architects and leads.
